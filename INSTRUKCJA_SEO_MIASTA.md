
# SEO DUZE MIASTA - WROOMER.PL

## Co dodano dla pozycjonowania?

### 1. Duze miasta (35 miast)
W footerze jest teraz grid z linkami:
Ogłoszenia Warszawa, Kraków, Wrocław, Gdańsk, Katowice, Poznań, Łódź...
Każdy link filtruje ogłoszenia po mieście i zmienia title na:
"Ogłoszenia motoryzacyjne Warszawa - WROOMER.PL | 3 auta"

### 2. Literowki WROOMER
W kodzie są słowa kluczowe:
wroomer, wromer, wrommer, vroomer, broomer, wroomer.pl
Dzieki temu jak ktoś wpisze zle, Google i tak pokaże WROOMER.PL

### 3. Sitemap z miastami
sitemap.xml zawiera teraz 35 URLi:
https://www.wroomer.pl/#miasto-Warszawa
https://www.wroomer.pl/#miasto-Krakow
...
Google zaindeksuje je jako podstrony.

### 4. Jak to działa w praktyce?
- Klient wpisuje w Google "ogłoszenia motoryzacyjne Warszawa"
- Google pokazuje wroomer.pl bo w footerze jest "Ogłoszenia Warszawa"
- Klient klika link Warszawa -> filtruje ogłoszenia z Warszawa w lokalizacji
- Jeśli brak ogłoszeń, pokazuje CTA "Dodaj pierwsze ogłoszenie w Warszawa"

### 5. Co zrobic teraz?
1. Wgraj index.html, sitemap.xml, robots.txt z tego ZIPa na GitHub
2. W GSC -> Poproś o zaindeksowanie -> https://www.wroomer.pl/
3. W GSC -> Mapy witryn -> wyslij nowy sitemap.xml
4. Za 24-48h w GSC -> Wydajność -> zobaczysz frazy "ogłoszenia Warszawa" itp

### 6. Następny krok - prawdziwe podstrony (opcjonalnie)
Jeśli chcesz mieć /warszawa /krakow jako osobne URL (lepsze SEO niż #miasto-), powiem Ci jak zrobić routing w GitHub Pages.
