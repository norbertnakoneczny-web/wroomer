WROOMER.PL - INSTRUKCJA WGRANIA NA VERCEL / GITHUB

PROBLEM: Masz 5 plików + folder blog i nie wiesz jak wgrać
ROZWIĄZANIE 1 (NAJPROSTSZE - VERCEL DRAG & DROP):
1. Wejdź na vercel.com → Twój projekt wroomer-pl → Settings → Deployments
2. Przeciągnij plik wroomer_VERCEL_CLEAN.zip na stronę Vercel - Vercel sam rozpakuje!
3. Gotowe - kliknij Redeploy

ROZWIĄZANIE 2 (GITHUB - 2 minuty):
1. Wejdź na github.com/twoj-nick/wroomer-pl
2. Kliknij "Add file" → "Upload files"
3. PRZECIĄGNIJ CAŁY FOLDER rozpakowany (zaznacz wszystkie 5 plików + folder blog) na okno przeglądarki
4. GitHub sam utworzy folder blog
5. Kliknij Commit changes
6. Vercel sam się zaktualizuje

ROZWIĄZANIE 3 (TYLKO 3 PLIKI - DLA CIEBIE):
W tym ZIP masz tylko 3 pliki - wystarczy wgrać te 3:
- index.html
- admin.html  
- vercel.json
Reszta (sitemap, robots, blog) jest już w kodzie index.html i działa automatycznie!

JAK WGRAC 3 PLIKI:
1. Na GitHub usuń wszystkie stare pliki (zaznacz wszystko → Delete)
2. Kliknij Upload files
3. Przeciągnij 3 pliki z tego ZIP
4. Commit
5. Gotowe!
