Krok 1: Skopiuj z Supabase (Mac: Cmd+C / Cmd+V)

Wejdź na supabase.com → Twój projekt → Project Settings → Data → API
Skopiuj Project URL i anon public key

Krok 2: Wklej tutaj i zapisz

Zapisuję w przeglądarce (localStorage) — nie musisz edytować żadnego pliku. Możesz to zrobić na Macu w Safari/Chrome.
