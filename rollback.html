Vercel Token - raz
1. vercel.com/account/tokens -> Create Token -> nazwa WROOMER-ROLLBACK -> Create
2. Kopiuj token vercel_... i wklej wyzej
3. Klikasz Pobierz wersje -> widzisz wszystkie wersje z data, READY/ERROR
4. Klikasz 1-KLIK PRZYWROC przy dzialajacej z 10h temu -> za 20s wroomer.pl wraca
